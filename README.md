# Fixed-Point Iteration in R / R ile Sabit Nokta İterasyonu

### 🇬🇧 English
This repository contains two implementations of the **Fixed-Point Iteration** method in R:
- **Basic Approach (`fixed_point_method`):** Returns only the final approximated root once the tolerance threshold is met.
- **Tabular Approach (`fixed_point_method_table`):** Stores and displays each iteration step (`n`) and its corresponding approximation (`gn`) in a structured `data.frame`.

**Files:**
- `fixed_point_iteration_en.R` (English documented script)
- `sabit_nokta_iterasyonu_tr.R` (Turkish documented script)

---

### 🇹🇷 Türkçe
Bu depo, Nümerik Analiz yöntemlerinden **Sabit Nokta İterasyonu (Fixed-Point Iteration)** algoritmasının R dilindeki iki farklı uygulamasını içerir:
- **Temel Yaklaşım (`sabit_nokta_metodu`):** Belirlenen hassasiyet eşiğine ulaşıldığında yalnızca yakınsanan son kök değerini döndürür.
- **Tablolu Gösterim (`sabit_nokta_metodu_tablo`):** Her bir iterasyon adımını (`n`) ve o adımdaki yaklaşık değeri (`gn`) düzenli bir `data.frame` tablosu olarak sunar.

**Dosyalar:**
- `sabit_nokta_iterasyonu_tr.R` (Türkçe açıklamalı kod dosyası)
- `fixed_point_iteration_en.R` (İngilizce açıklamalı kod dosyası)
